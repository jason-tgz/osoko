# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of Osoko seriously. All screenshot processing, OCR, downscaling, and redaction run strictly on-device with zero telemetry and zero network calls.

If you believe you have found a security vulnerability in Osoko:

1. Please do **not** disclose it publicly via a GitHub issue.
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/lostmusician/osoko/security/advisories/new) or by contacting the maintainer directly.
3. You will receive an acknowledgment within 48 hours, and a fix will be published promptly.
